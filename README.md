# Tasks – Módulo 1 de Programação Orientada a Objetos

<p>&emsp;Atividades práticas desenvolvidas durante os estudos de <strong>Programação Orientada a Objetos (POO)</strong> utilizando <strong>Java</strong>, realizadas no <strong>Módulo 1</strong> da unidade curricular Programação Orientada a Objetos.</p>

---

## 📚 Conteúdos praticados

- Linguagem de programação Java;
- Programação Orientada a Objetos (POO);
- Classes e objetos;
- Atributos e métodos;
- Estruturas condicionais;
- Estruturas de repetição;
- Entrada e saída de informações;
- Tratamento de exceções;
- Desenvolvimento de interfaces gráficas;
- Geração de números aleatórios.

---

## 💻 Tecnologia utilizada

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)

## 📝 Atividades

### Task 1 — Calculadora GUI

Desenvolvimento de uma calculadora utilizando interface gráfica para realização de operações matemáticas.

### Task 2 — Calculadora de IMC

Desenvolvimento de uma aplicação para cálculo do Índice de Massa Corporal (IMC), com classificação do resultado.

### Task 3 — Conversor de Temperatura

Desenvolvimento de uma aplicação para conversão entre diferentes escalas de temperatura.

### Task 4 — Jogo de Adivinhação

Desenvolvimento de um jogo em Java no qual o usuário deve tentar adivinhar um número gerado aleatoriamente.
